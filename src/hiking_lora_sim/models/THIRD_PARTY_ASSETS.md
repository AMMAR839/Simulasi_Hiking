# Third-Party Gazebo Assets

Some visual assets in this directory are copied from the OSRF Gazebo model database.

- Source: https://github.com/osrf/gazebo_models
- Local clone: `external_assets/gazebo_models`
- Source revision used: `8163eb4`
- License from upstream repository: Creative Commons Attribution 3.0 Unported

Copied / derived assets:

- `pine_tree`
- `hiking_lora_pine_tree`, package-local copy of `pine_tree` used by generated forests
- `oak_tree`
- `hiking_hiker`, derived from upstream `person_walking`

The current generated hiking worlds use the package-local `hiking_lora_pine_tree` asset for every forest tree. The copied `pine_tree` and `oak_tree` assets are retained as local reference assets, but `src/hiking_lora_sim/tools/generate_mountain_world.py` no longer includes them in the forest.

The procedural terrain, forest trees, simple LoRa relay poles, route markers, stream, shrubs, rocks, base camp, and local LoRa placement logic are generated by `src/hiking_lora_sim/tools/generate_mountain_world.py`.
